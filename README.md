The Weather App is a web application developed to display real-time weather information for several cities in Romania. To retrieve weather data, I integrated the OpenWeather API, which provides details such as temperature, weather conditions, humidity, and wind speed.

The application sends requests to the API based on selected city names, then processes and displays the data in a user-friendly interface. Users can quickly check the weather for cities like Bucharest, Cluj-Napoca, Iași, and Timișoara.

The app was built using HTML, CSS, and JavaScript, and the API integration was implemented using fetch/axios to dynamically retrieve and display the data.
